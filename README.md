# quantum-acoustic-simulation
# 🔊 Quantum Acoustic Simulation

## Overview

This project explores the **fundamental connection between acoustic wave propagation and quantum wave mechanics** through simple computational simulations.

Both sound waves and quantum wavefunctions are governed by wave equations, and this repository aims to provide an intuitive and visual understanding of their similarities using numerical methods.

---

## Objectives

* Simulate a **1D acoustic wave propagation**
* Visualize wave behavior over time
* Draw parallels with **quantum wavefunctions**
* Build a foundation for **interdisciplinary research** between acoustics and quantum systems

---

## Key Concepts

* Wave equation
* Superposition
* Boundary conditions
* Wave propagation
* Quantum wavepacket (introductory level)

---

## Tools Used

* Python
* NumPy
* Matplotlib
* Jupyter Notebook

---

## Simulations Included

### Acoustic Wave Simulation

A numerical simulation of a 1D wave equation showing how disturbances propagate through a medium.

### Quantum Analogy

A basic Gaussian wavepacket visualization to illustrate similarities with quantum systems.
